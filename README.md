# Autoevaluación para el Registro SIR de la Comunitat Valenciana

Calcula una puntuación por módulo y genera un informe descargable. Pensada para microempresas de 1 a 9 personas empleadas. Cubre 31 indicadores ESG del Decreto 200/2022 de la Comunitat Valenciana (castellano, valenciano e inglés).

Es software libre. Los datos que se escriben en la herramienta se procesan en el navegador y no se envían a ningún servidor.

**Versión en línea:** https://yel-martinez-portfolio.com/recursos/autoevaluacion-para-el-registro-sir-de-la-comunitat-valenciana/

## Uso

Abre `index.html` en un navegador. No hace falta servidor ni instalación.

Archivos:

- `index.html`: la herramienta, como página independiente.
- `script.js`: la lógica (todo está dentro del espacio de nombres de la herramienta para no chocar con otro código).
- `style.css`: los estilos (acotados al contenedor de la herramienta).

## Dependencias

Ninguna: JavaScript y CSS sin librerías ni paso de compilación.
